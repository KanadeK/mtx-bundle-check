# Security

Version 0.1.x is the supported line. For a suspected vulnerability, use
[GitHub private vulnerability reporting](https://github.com/KanadeK/mtx-bundle-check/security/advisories/new)
if available. Otherwise open a minimal public issue asking for a private contact;
do not disclose exploit details, confidential data or credentials in that issue.

The CLI reads only explicitly supplied local inputs. It does not execute input
code or send telemetry. Use trusted, quiescent snapshots and operating-system
limits when inspecting untrusted files. A successful check only covers the
documented checks; it is not a security certification or a scientific conclusion.
